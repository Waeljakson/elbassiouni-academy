# مجموعة البسيوني التعليمية

تطبيق عربي لإدارة طلاب مجموعة البسيوني لعلم النفس والفلسفة والمنطق، يعمل كواجهة ثابتة على GitHub Pages مع Supabase للمصادقة وقاعدة البيانات.

## التشغيل

افتح `index.html` عبر خادم محلي أو رابط GitHub Pages. الاتصال يستخدم مفتاح Supabase القابل للنشر فقط، والحماية الفعلية مطبقة بسياسات Row Level Security.

## تهيئة أول حساب معلم

1. أنشئ الحساب من واجهة التطبيق وأكد البريد الإلكتروني.
2. من Supabase SQL Editor نفذ، بعد استبدال البريد:

```sql
update public.profiles p
set role = 'teacher'
from auth.users u
where p.id = u.id and u.email = 'TEACHER_EMAIL';
```

الحسابات الجديدة تبدأ بدور طالب كإجراء أمني. يغير المعلم الدور ويربط الطالب أو ولي الأمر بالسجلات المناسبة.

## الصلاحيات

- المعلم: جميع البيانات، المدفوعات والمصروفات والحسابات.
- السكرتيرة: الطلاب والحضور والاختبارات والدرجات، دون المدفوعات أو المصروفات.
- الطالب: بياناته وحضوره ودرجاته ومدفوعاته فقط.
- ولي الأمر: بيانات الأبناء المرتبطين به فقط.
